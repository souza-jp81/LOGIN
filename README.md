## 📌 Sobre o projeto

Interface visual de login criada para praticar formulários, posicionamento, ícones, estados de foco e composição de uma tela moderna. O projeto representa apenas a camada de apresentação.

> **Observação:** O projeto não possui autenticação real, banco de dados ou armazenamento de credenciais. É uma interface front-end para fins de estudo.


---

## ✨ Funcionalidades

- Campo para nome de usuário.
- Campo protegido para senha.
- Opção visual de lembrar acesso.
- Links de recuperação de senha e cadastro.
- Ícones integrados aos campos.
- Fundo estilizado e layout centralizado.

---

## 🛠️ Tecnologias utilizadas

**HTML5**, **CSS3**, **GitHub Actions**.

---

## 📂 Estrutura do projeto

- `index.html` — formulário e elementos da tela
- `styles.css` — estilos, fundo e componentes
- `.github/workflows/` — automação configurada no repositório

---

## ▶️ Como executar

1. Clone o repositório: `git clone https://github.com/souza-jp81/LOGIN.git`
2. Acesse a pasta: `cd LOGIN`
3. Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no VS Code.

O projeto não exige instalação de dependências nem configuração de servidor para uso local.
